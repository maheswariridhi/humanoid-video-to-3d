# Examples

Commit a small example here so reviewers can see results without running anything:

```
examples/
├── room.mp4                 # a short input clip (keep it small, e.g. < 20 MB)
├── output/
│   ├── point_cloud.ply      # the reconstructed cloud
│   └── preview.png          # a screenshot of the cloud (the "money shot")
```

Generate `point_cloud.ply` by running `reconstruct.ipynb` in Colab, then download
it (and a screenshot of the inline viewer) and drop both here.
